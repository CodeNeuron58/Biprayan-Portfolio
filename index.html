RxGuard

Agentic Medication Safety Copilot

  • —Built a clinical agent as a cyclic LangGraph state machine that extracts a structured patient profile from free-text notes, plans research steps, retrieves guideline evidence from FAISS, and reasons about medication risk.
  • —Added a Safety Critic node that rejects any finding without explicit guideline citations and sends the agent back to re-plan; a retry cap and a confidence check end hard cases in a safe report instead of a loop.
  • —Runs fully locally (MedGemma-4B via Ollama, EmbeddingGemma embeddings), so patient notes never leave the machine; every node returns Pydantic-validated JSON, and a Streamlit UI streams each reasoning step live.

Hybrid-Search RAG Chatbot
